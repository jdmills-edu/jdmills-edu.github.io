FT-891 Shack Console

Live

A browser console for a Yaesu FT-891 HF radio, with CAT control, a waterfall, and FT8 and CW decoding.

Since Nov 2026Touched 7 days ago

  • Python
  • WebSockets
  • JavaScript
  • Hamlib CAT
  • WSJT-X jt9
More

It talks to the radio through a DigiRig Mobile interface. A beginner-friendly Simple view sits beside a Pro view with every CAT control, meters and a live waterfall. It decodes FT8 with WSJT-X's jt9, and decodes Morse with automatic pitch and speed, giving each transmitter its own line.

It knows which frequencies each US licence class may use (47 CFR §97.301/305/307), estimates RF exposure from FCC OET 65 duty factors, and shows band conditions from NOAA and ionosonde data. It's receive-only by default, and a Bluetooth knob can tune the VFO.

Local LLM server

Live

One local model on two consumer GPUs, shared by every AI feature on this page.

Since May 2026

  • llama.cpp
  • CUDA
  • Qwen
  • distrobox
  • systemd
More

llama.cpp's llama-server runs a 27B Qwen 3.8 finetune (Q4_K_M) with a multi-token-prediction draft head and vision, split across an RTX 5070 Ti and an RTX 4070 on OCuLink. Measured along the way: without GPU peer-to-peer, tensor parallel gains 35–40% decode but loses 30–50% prefill, so it wins for chat and agent loops. A finite reasoning budget ended runaway thinking, and moving from Q5 to Q4 stopped a silent CPU spill-over, taking decode from about 35 to 42–55 tokens/s. Small shims let Claude Code and a qFlipper fork talk to it.
